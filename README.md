# Task Manager Web Application

Simple task manager web application

## Tech stack
- Backend: Node.js (REST API)
- Frontend: Free choice
- Database: Relational (MySQL)

## API Endpoints
- GET /tasks
- POST /tasks

## Database Design
Table: tasks
- id
- title
- description
- status
- due_date
